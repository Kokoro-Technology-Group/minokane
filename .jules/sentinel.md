## 2025-05-27 - [CRITICAL] Prevent Timing Attacks on API Key Verification
**Vulnerability:** The API key validation in the FastAPI route dependency `verify_api_key` used a direct string comparison (`api_key != settings.api_key`). String comparison in Python short-circuits on the first mismatched character, creating a timing attack vulnerability where an attacker can incrementally guess the valid API key by measuring response times.
**Learning:** Even internal or "simple" API key validation needs to use constant-time comparisons if the key length is short or the application is exposed to timing variations over a network. While network jitter often masks this, it remains a critical vulnerability on local networks or highly consistent connections.
**Prevention:** Always use `secrets.compare_digest(a, b)` (or `hmac.compare_digest`) for comparing sensitive strings like API keys, tokens, or passwords, instead of standard equality operators (`==`, `!=`). Note that `secrets.compare_digest` requires both arguments to be strings (or bytes), so `None` checks must precede the comparison.
