## 2025-02-28 - Timing Attack Vulnerability in API Key Verification
**Vulnerability:** The API key in `backend/app/routes/questions.py` was being validated using the standard equality operator `!=`, making the endpoint vulnerable to timing attacks. This could potentially allow an attacker to guess the API key character by character by measuring the response time of the verification process.
**Learning:** Python's standard string comparison (`==`, `!=`) exits as soon as it finds a difference, which introduces a time difference based on how much of the string matches. This is a common pattern when validating custom header-based tokens like `X-API-Key`.
**Prevention:** Always use `secrets.compare_digest` for cryptographic or sensitive string comparisons. Furthermore, since FastAPI `Security` headers might be `None` (if `auto_error=False`), gracefully handle the `None` case (`if not api_key or not secrets.compare_digest(...)`) because `compare_digest` raises a `TypeError` if one of the arguments is `None`.
